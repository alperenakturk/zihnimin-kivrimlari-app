        Bağlantı

        Uygulama verini doğrudan gizli GitHub reponda okur ve yazar. Anahtar yalnızca bu cihazda saklanır.

        Anahtar nasıl alınır?
        1. github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
        2. Repository access: Only select repositories → yalnızca kasa reposu.
        3. Permissions → Repository → Contents: Read and write. Başka izin verme.
        4. Süreyi 1 yıl seç, oluştur, buraya yapıştır.

        Demo

        Anahtarsız denemek için: adrese ?demo ekle. Demo modunda hiçbir şey kaydedilmez.
