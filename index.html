                            Anahtar nasıl alınır?
                            1. github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
                            2. Repository access: Only select repositories → yalnızca kasa reposu.
                            3. Permissions → Repository → Contents: Read and write. Başka izin verme.

                            ✨ Yapay zekâ (Claude)

                            Açıkken kullandığın özellikte (ör. "Karalamadan iş çıkar") ilgili metin Anthropic'e gönderilir. Başka hiçbir veri gönderilmez.

                            Özellikler: Giriş → Karalamadan iş çıkar. Anahtar platform.claude.com → API Keys'ten alınır; harcama limiti koymanı öneririm.
